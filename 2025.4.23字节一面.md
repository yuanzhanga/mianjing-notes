## 浏览器进程线程

多进程多线程，主要包括浏览器进程，网络进程，渲染进程，GPU进程，进程包括多个线程

## 事件循环

消息队列：宏任务，微任务（高优先级）

渲染主线程：for循环，执行js代码，渲染

## 渲染原理

解析HTML树，css树，样式计算生成render树，开始布局，删除display:none的节点，分层，根据分层生成绘制指令，进入合成线程，分块，光栅化，画

回流：改变几何属性，重新生成布局树

重绘：改变颜色，重新生成绘制指令

transform:画阶段，不在渲染主线程，效率高

## 二叉树的最大深度

```js
//层序遍历
function maxDepth(root: TreeNode | null): number {
    let depth: number = 0;
    let res: number[][] = [];
    function level(cur: TreeNode | null, depth: number) {
        if (!cur) return;
        if (depth >= res.length) res[depth] = [];
        res[depth].push(cur.val);
        depth++;
        level(cur.left, depth);
        level(cur.right, depth);
    }
    level(root, depth);
    return res.length;
};

//递归
function maxDepth(root: TreeNode | null): number {
    if (root == null) {
        return 0
    }

    return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1
};

//迭代
var maxDepth = function (root) {
    if (!root) return 0
    let count = 0
    const queue = [root]
    while (queue.length) {
        let size = queue.length
        /* 层数+1 */
        count++
        while (size--) {
            let node = queue.shift();
            node.left && queue.push(node.left);
            node.right && queue.push(node.right);
        }
    }
    return count
};
```

## 比较两个对象是否相等

```js
    function com(o1, o2) {
      if(typeof o1 !== typeof o2) return false
      if (typeof o1 !== "object" || typeof o2 !== "object") {
        if (o1 === null && o2 === null) return false;
        return o1 === o2;
      }
      let k1 = Object.keys(o1);
      let k2 = Object.keys(o2);
      if (k1.length !== k2.length) return false;
      for (let key of k1) {
        if (!k2.includes(key) || !com(o1[key], o2[key])){
          return false;
        }
      }
      return true;
    }
```

## 发布订阅

```js
  class EventBus {
    constructor() {
      this.events = {};
    }
    //注册
    on(e, fn) {
      if (!this.events[e]) this.events[e] = [];
      this.events[e].push(fn);
    }
    //清空
    off(e, fn) {
      //如果没有传入fn，则清空该事件的所有监听函数
      if (!fn) {
        this.events[e] = undefined;
        return;
      }
      if (this.events[e]) {
        this.events[e] = this.events[e].filter((cb) => {
          return cb !== fn;
        });
      }
    }
    emit(e, ...arg) {
      if (this.events[e]) {
        this.events[e].forEach((cb) => {
          cb.apply(this, arg);
        });
      }
    }
    once(e, fn) {
      const onceFn = (...arg) => {//箭头函数
        fn.apply(this, arg);
        this.off(e, onceFn); //执行一次后移除监听
      };
      this.on(e, onceFn);
    }
  }
```

## 闭包

```js
    for(var i=0;i<5;i++){
        setTimeout(function(){
            console.log(i)
        }, 1000*i);
    }
//0s->5 1s->5 ...
//把i传给setTimeout，同步任务全完成后打印i，i是全局的5

    for(var i=0;i<5;i++){
        (function(i){
            setTimeout(function(){
                console.log(i)
            }, 1000*i); 
        })(i)
    }
//0s->0 1s->1 ...
//创建了一个新的作用域，将每次循环的i值作为参数传递进去，这样在setTimeout的回调函数中，i的值就是当前循环的值，而不是全局的i，每次循环都会创建一个新的闭包，保存了当前循环的i值，因此setTimeout的回调函数可以正确地打印出每次循环的i值
```
